🖥️ SmartTech – Full-Stack E-Commerce Application

SmartTech is a full-stack e-commerce web application for selling technology products.

✨ Features

The application enables:
User registration
Email verification
JWT-based login
Viewing products
Searching products by name suffix
Filtering products by category
Adding products to cart
Secure online payments with Stripe
Viewing user orders


📚 About the Project

This application was built to deepen my knowledge of:
REST API development
Docker
Email integration
Online payment systems
Modern React architecture
It represents a major step forward in my full-stack development journey.


⚙️ Backend (Spring Boot)

For the backend, I used Spring Boot, applying SOLID principles and clean architecture practices.

What I learned and implemented:

RESTful API development using @RestController
DTO pattern for better separation between layers
Endpoint testing with Postman
Proper use of HTTP methods (GET, POST, PUT, DELETE)
JWT authentication & authorization
Role-based access (USER / ADMIN)
Docker & docker-compose for running the database locally
Gmail Mail Sender integration for email verification
Stripe payment integration
Secure handling of secret API keys using environment variables
This project significantly improved my understanding of backend architecture and real-world API security.

🎨 Frontend (React)

Before this project, I had only worked with:

HTML
CSS
Bootstrap
Thymeleaf

To build a more scalable and modern application, I challenged myself to learn React.

What I learned:

React architecture & component-based design
React Router
Axios for API communication
Context API for JWT authentication
Custom hooks
Repository pattern for API abstraction
Protected routes
State management best practices

This project helped me transition from traditional server-rendered applications to modern frontend architecture.

🚀 Deployment

The application was deployed on Render:
Backend (Spring Boot)
Frontend (React)
Database

Since it was hosted on the free tier plan, it was available for one month.
